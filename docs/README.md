# Documentation Index

Overview of documentation files in this directory:

- [SETUP.md](SETUP.md) — Complete setup, configuration, everyday usage guide, settings reference, and troubleshooting.
- [architecture.md](architecture.md) — Map of the codebase, project layout, data flow, key modules, and developer commands.
- [openapi.json](openapi.json) — OpenAPI 3.1 specification for all dashboard backend `/api/` endpoints (served at `/docs/api`).
- [MANUAL-TESTS.md](MANUAL-TESTS.md) — Manual testing checklist and test cases for UI, audio/video pipelines, and browser sign-in.
- [PRD-Phase-0.md](PRD-Phase-0.md) — Specification for Phase 0: YouTube playlist ingestion, categorization, and watch-time engine.
- [Phase-0-Research-and-Improvements.md](Phase-0-Research-and-Improvements.md) — Phase 0 research review, revised requirements, and architectural improvements.
- [PRD-Phase-1.md](PRD-Phase-1.md) — Specification for Phase 1: web dashboard, transcripts, search, triage, and summaries.
- [PRD-Phase-2.md](PRD-Phase-2.md) — Specification for Phase 2: library-wide Q&A with cited video moments and meaning search.
- [PRD-Phase-2.5.md](PRD-Phase-2.5.md) — Specification for Phase 2.5: local Whisper transcription, slide extraction/reading, and multi-lane queues.
- [PRD-Phase-3.md](PRD-Phase-3.md) — Specification for Phase 3: rich knowledge synthesis topic pages and cross-video learning.
- [PRD-Libraries.md](PRD-Libraries.md) — Specification for multiple isolated libraries with separate categories, ratings, and goals.
- [PLAN-cross-platform.md](PLAN-cross-platform.md) — Plan and notes for cross-platform support across Linux, macOS, and Windows.
- [PLAN-remove-playlist.md](PLAN-remove-playlist.md) — Plan and design for removing a playlist safely while preserving user notes.
- [Mobile-options.md](Mobile-options.md) — Research and evaluation of mobile access options (remote UI, PWA, local AI).
